Ejercicios Java
#Emmanuel Antonio Dzib Galeaana
Descripcion
El repositorio incluye una serie de ejercicios prácticos que refuerzan estos conocimientos:

Ejercicio 1: Implementación de excepciones personalizadas en un sistema bancario.
Ejercicio 2: Desarrollo de un iterador utilizando una inner class en una estructura tipo pila (SimpleStack).
Ejercicio 3: Construcción de un sistema de tickets utilizando enums avanzados.
Ejercicio 4: Creación de un pipeline funcional para el procesamiento de productos.
Ejercicio 5: Diseño de un sistema de pizzas aplicando los patrones Builder y Decorator.

Este proyecto está orientado a fortalecer habilidades en diseño de software, escritura de código limpio y aplicación de buenas prácticas en Java.
